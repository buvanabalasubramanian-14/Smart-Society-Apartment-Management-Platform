Smart Society Apartment Management Platform

Project Overview

The Smart Society  Apartment Management Platform is a web-based application developed to simplify apartment management. It helps residents, administrators, and security staff manage complaints, visitors, maintenance payments, notices, and apartment services efficiently.

 Technologies Used

- Frontend: React.js
- Backend: Python Flask
- Database: MySQL
- AI Enhancement: Complaint Priority Recommendation

 Main Features

- User Login
- Resident Management
- Complaint Management
- Visitor Management
- Maintenance Management
- Notice Board
- AI-Based Complaint Priority
